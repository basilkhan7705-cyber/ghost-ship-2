# Ghost Hunter 👻

## About the Project
Ghost Hunter is a simple game made using JavaScript and p5.js. The main goal of the game is to click on the ghost as many times as possible within 30 seconds.

I made this project while learning p5.js and experimenting with basic JavaScript functions. It took me around 3 hours to complete.

## How to Play
1. Click on the screen to start the game.
2. A ghost will appear somewhere on the screen.
3. Click on the ghost to earn 1 point.
4. After clicking, the ghost will move to a new random location.
5. Try to get as many points as possible before the 30-second timer ends.
6. When the game ends, your final score will be displayed.
7. Click again to restart the game.

## Features
- 30-second countdown timer.
- Score counter.
- Ghost appears at random positions.
- Obstacles on the screen.
- Ghost does not spawn inside obstacles.
- Simple start and game over screens.
- Light purple background with stars and dark purple corners.

## Controls
- **Mouse Click:** Start the game and catch the ghost.
